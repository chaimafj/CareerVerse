# Django API - CareerVerse

Cette application Django constitue le backend de CareerVerse.

## Modules principaux

- users
- profiles
- careers
- simulations
- labs
- results
- recommendations
- ai

## Démarrage

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
